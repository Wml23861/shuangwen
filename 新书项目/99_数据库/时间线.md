# 时间线

> 宪法第38条：所有章节完成后检查时间线。禁止时间矛盾。

## 故事历法

- 以"界渊元年"计：裂缝首次出现为元年。
- 顾北辰卒于界渊40年（十年前）。
- 故事开局：界渊50年，秋。

## 大事件年表

| 时间 | 事件 |
|---|---|
| 界渊元年 | 全球裂缝出现，蚀兽入侵 |
| 界渊15年前后 | 顾北辰创立源武体系 |
| 界渊20年 | 顾北辰与贺擎苍结义，收齐岳为徒；与云萝相识 |
| 界渊30年 | 白守拙拒签"北辰案"相关定性，白家被贬（待揭示细节） |
| 界渊40年 | 北海之眼，顾北辰"走火入魔"死（实际被围杀）。贺擎苍建总会，封七柱 |
| 界渊41至50年 | 药剂垄断体系建立，源蚀症泛滥，教科书改版 |
| 界渊50年秋 | 林夜（17岁）被周子昂打死；顾北辰在其体内醒来（第1章） |

## 季节与天气备注

- 开局深秋：临江多夜雨（第1、8章夜戏可用）。
- 第23章生日：初冬第一场冷雨。
- 第30章：初冬，云麓城比临江暖（更靠南/沿江气候，写作时统一）。

- 林夜17，林溪13（差4岁，父母亡故时林夜11、林溪7，可自理逻辑成立）。
