## 项目核心定义

- 书名：《我还没死，你们急什么》（2026-09-17定稿，十三轮候选设计后用户拍板；简介主推 00_项目总纲/简介候选.md 版本四）
- 题材：都市高武
- 模式：「身后归来流」（本项目原创结构，详见 00_项目总纲/项目定位.md）
- 一句话：主角重生到自己死后第十年，整个高武世界建立在他被窃取的天才成果之上，杀他的人是现在的世界英雄，他以无名之身回来收账。
- 主角：顾北辰（前世，北辰圣者）／林夜（今生，17岁，临江市）
- 感情线：单女主（白青梧），慢热，克制副线
- 金手指：他是世界修炼体系的作者本人 + 前世记忆与遗产。无系统、无面板
- 每章目标字数：2000至2500字（番茄常规，可按投稿要求调整）
- 核心发动机：**信息差**（L0 第4条：主角知道 → 读者知道 → 其他人不知道 → 认知崩塌）

## 命令对应

### 初始化
适用于全新项目（本项目已完成，保留作模板）：执行启动协议A-M → 确认题材方向 → 建立本目录结构 → 产出 00_项目总纲 全套初版 → 数据库初版。

### 设计新书
1. 读 L0 第1-5条（商业目标、最高原则、核心发动机）
2. 依次产出：题材与模式 → 一句话卖点 → 主角与金手指 → 核心信息差设计 → 五层爽感分布 → 感情线策略
3. 全部写入 00_项目总纲/ 对应文件
4. 每个设计决策必须回答 L0 第1条之问："读者看这一段，会不会更想继续看？"

### 设计前十章
1. 读 L0 第31-32条（第一章优先级、前十章商业闭环）、L1 第6-7条
2. 读 04_剧情总纲/全书总纲.md、04_剧情总纲/第一阶段.md
3. 按"认识主角→现实问题→阻碍→异常能力→第一次反击→第一次爽点→身份秘密→更大问题"闭环排布十章
4. 逐章产出章节卡（L1 第43条格式），写入 05_章节规划/前10章.md
5. 逐章过 L0 第49条26问，无明确答案的章节重排

### 设计前三十章
1. 读 L0 第33条（前三十章验证结构）、L1 第8条
2. 确认八项任务落点：主角立住、核心爽点立住、世界规则立住、周家线阶段高潮、妹妹线情感牵引、身份秘密扩大、杜衡线启动、更大世界入口
3. 在前10章基础上扩展为30章节奏表，标注每章爽点类型（L0 第28条九种爽法，禁止连续三章同型）和钩子
4. 写入 05_章节规划/前30章.md

### 继续写
1. 先过 L0 第49条26问（商业/爽感/悬念/剧情/长线五组），答案不明先补章节卡
2. 执行 L1 第42条十二步读取（数据库、章节卡、前一章正文等）
3. 执行 L1 第44-53条十遍写作流程
4. 存至 正文/当前卷/，更新"每章完成后必须更新的文件"清单全部8项
5. 成稿后走 L0 第50条五轮商业终审（普通读者/爽感/追读/AI痕迹/连续性，连续性不重复L1第49条已做的部分）
6. 输出送检版本存档至 E:\爽文\检测实验\

### 写第一章
执行 L1 第89条流程，并叠加 L0 第31条六要素检查（人物→环境→异常→核心冲突→主角特殊性→阅读钩子）。

### 审查最新章节
1. 执行 L1 第79条审查命令
2. 执行 L0 第50条五轮审查（分工合并：连续性以 L1 第49条结果为准，不重复）
3. 对照 90_审查/ 五份标准文件逐项核对
4. 输出审查报告：问题清单按 CRITICAL/HIGH/MEDIUM/LOW 分级，给出修改建议但不自动改正文（改动需用户确认）

### 模拟读者
以首次点开本书的番茄读者身份冷读指定章节（默认最新章）：
1. 只回答三个问题：好不好看？哪一段想弃书？看完会不会点下一章？
2. 对照 L0 第26条情绪曲线，标出本章实际情绪落点（好奇/期待/紧张/憋屈/反击/爽/惊讶/怀疑/震撼/感动/更大期待）
3. 检查"憋屈是否有出口"（L0 第26条：可以虐主角，不能虐读者）
4. 不做文学分析，不给修改方案，只给真实阅读反应

### 检查爽点
1. 读 07_爽点数据库/爽点记录.md，统计近10章爽点类型分布
2. 对照 L0 第6-9条五层爽感（即时爽/能力爽/认知爽/身份爽/历史爽），检查是否长期停留在第一层
3. 对照 L0 第28条，检查是否陷入爽点流水线（嘲讽→淡定→出手→震惊循环）
4. 对照 L1 第19-20条爽点密度控制与每章爽感审查
5. 输出：爽点分布表 + 疲劳预警 + 下一章建议爽法（优先使用近期未用的类型）

### 检查短剧 / 检查连续性
执行 L1 对应命令（第24-25条短剧镜头测试；第38-39条时间线与连续性数据库），标准文件见 90_审查/。
