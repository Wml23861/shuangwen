# 第一阶段：临江立足（1至30章）

> 对应宪法第8条：前三十章是第一个商业验证周期。

## 阶段主题

活下去，救妹妹，灭周家，在临江市站稳脚跟。
同时埋下全书所有主线的种子：身份线、药剂线、白家线、大人物视野线。

## 阶段结构（三幕）

### 第一幕：死而复生（1至10章）

- 主角核心目标：活命 + 搞钱救妹妹 + 藏住身份。
- 主要冲突：周家的灭口压力 + 妹妹的药费死线 + 遴选。
- 关键事件：太平间醒来 → 电视里的仇人 → 地下拳场第一桶金 → 遴选打脸周子昂 → 假药破局 → 反杀觉醒者打手 → 周炳坤倒台 → 大比画面被大人物看到。
- 爽点节奏：小爽密集（第4、6、7、8、9章）+ 第10章阶段小高潮。
- 详见 05_章节规划/前10章.md。

### 第二幕：周家清算（11至20章）

- 主角核心目标：把周家连根拔起 + 建立药剂替代渠道。
- 主要冲突：周炳坤的垂死反扑（请出杜衡的人）+ 学院体系的排斥 + 白青梧的逼近试探。
- 关键事件：
  - 替代药剂铺开，动了云氏在临江的根基，杜衡的人介入调查。
  - 周子昂被废（决斗或规则内制裁，主角借规则杀人，不脏自己的手）。
  - 周炳坤勾结防区走私的证据链完成（九指陈 + 守备军内白家旧部协助）。
  - 白青梧发现林夜手法与曾祖手稿同源（第18章前后，重要伏笔推进）。
  - 周家覆灭（第20章，阶段中爽点）。
- 第一次真正代价（宪法第8条要求）：第15至17章，主角为救林溪提前使用替代药方，药方流入市面太快，引来杜衡注意，临江身份开始危险。他意识到自己冒进了。

### 第三幕：临江定局（21至30章）

- 主角核心目标：应对杜衡 + 决定下一步舞台。
- 主要冲突：杜衡亲自来临江（五境武师，主角当前打不过）+ 云氏药业江南分公司对"假药"源头的清剿。
- 关键事件：
  - 主角不硬拼，用三招拆解：把周炳坤的罪证送给杜衡的政敌（借刀）；让"假药"源头指向已死的周炳坤（金蝉脱壳）；在杜衡面前立一个"有背景的神秘年轻人"人设（借势）。
  - 杜衡吃了暗亏但抓不到人，把"临江有个疑似有传承的年轻人"上报江南总部（世界扩大钩子）。
  - 秦教授线收束：老人公开为林夜的"理论"背书，被学院排挤，主角安排他进入自己的下一步棋（温情 + 立威）。
  - 白青梧与主角达成试探性同盟（她没问身份，他没说谎）。
  - 林溪病情稳住，第一次露出"想觉醒"的念头（下一阶段钩子）。
  - 第30章：主角收到江南大区首府"云麓城"的契机（学院交流 / 白家牵线 / 杜衡反向邀请，三选一，写作时定），临江市篇收束，舞台扩大。
