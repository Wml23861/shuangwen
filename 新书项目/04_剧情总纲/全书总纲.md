# 全书总纲

## 一句话主线

顾北辰重生归来，从临江市最底层起步，一边活下去、保护妹妹，一边一层层收回被窃取的一切，最终掀翻杀死他的人建立的神像，揭开界渊的真相，完成他死前没做完的事。

## 六层结构（宪法第9条）

1. 即时剧情：每章的具体冲突（活下去、搞钱、打脸、藏身份）。
2. 短期目标：几章内的目标（救妹妹、灭周家、进遴选）。
3. 阶段目标：几十章内的目标（临江立足、扳倒杜衡、进入更高舞台）。
4. 长期主线：复仇七柱 + 昭雪 + 揭开界渊真相 + 关闭界渊。
5. 人物关系：与白青梧的信任线、与云萝的旧情考场、与林溪的亲情、七柱之间的裂缝。
6. 世界扩张：临江市 → 江南大区 → 京畿 → 各大界渊 → 界渊另一边（预留）。

## 卷结构规划

### 第一卷：临江暗涌（1至100章）

- 主题：立足。从尸体到临江市无人敢惹的"林先生"。
- 阶段敌人：周家（1至30章）→ 杜衡（31至80章）→ 江南大区层面的首次正面碰撞（81至100章）。
- 卷末状态：妹妹病情受控；白青梧成为知情边缘的同盟；主角进入某位大人物的暗中视野；身份线在"最危险的一次差点暴露"中收卷。

### 第二卷：江南棋局（101至250章，规划容量）

- 主题：产业战。从扳倒一个人到扳倒一套体系（江南药剂网络）。
- 引入：界渊防区剧情（蚀兽首次正面登场）、齐岳派系、白崇山。
- 卷末：云氏药业江南体系崩塌，云萝第一次正面注意到"林夜"。

### 第三卷：京畿风云（251至450章，规划容量）

- 主题：进入七柱的牌桌。身份悬疑进入高危期。
- 贺擎苍第一次正式注意到他。莫天机立场揭晓。云萝真相部分揭开。

### 第四卷及以后（预留）

- 围杀真相完整揭开 → 七柱体系崩塌 → 界渊真相 → 终局：关闭界渊 / 完成第九境。
- 保留调整空间，以数据与剧情生长为准（宪法第84条）。

## 爽点升级总线（宪法第4条）

1. 小胜（临江街头与学院）
2. 逆转（灭周家）
3. 大胜（扳倒杜衡）
4. 身份揭露（白青梧确证 → 更大范围泄露 → 仇人起疑）
5. 规则改变（药剂骗局局部揭穿 → 体系真相公开）
6. 世界扩大（临江 → 江南 → 京畿 → 界渊）
7. 新的巨大危机（七柱出手 / 界渊异变）
8. 更高层级的解决（昭雪与终局）

## 情绪主线

委屈与昭雪。从"全世界都在骂我"到"全世界都知道了"。
这是贯穿全书的情绪引擎，比单纯的变强多一层读者粘性。
