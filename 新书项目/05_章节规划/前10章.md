# 前十章商业验证结构

> 宪法第7条：每章必须回答——核心吸引点是什么？读者期待什么？在哪里释放？为什么必须点下一章？
> 每章字数目标：2000至2500字。

---

## 第1章 太平间

- 核心吸引点：死人在停尸台上睁开眼 + 电视上仇人正在纪念他。
- 场景：仁爱诊所停尸间 → 平民区街道 → 筒子楼家中。
- 剧情：林夜（顾北辰）在停尸台醒来，记忆融合（压缩到几百字内，只给生存必需信息：这是十年后；这身体被周家打死了；他有个妹妹在等药）。听到医生出去给周家打电话"处理尸体"，他用前世手法无声放倒来收尸的两个人，拿走他们身上的现金，深夜回家。妹妹林溪发着烧在等他。电视里正播"北辰圣者逝世十周年纪念直播"，贺擎苍在纪念碑前致辞："我此生最痛，是没能救回北辰兄。"
- 释放：两个爽点——死而复生的悬念本身；他看着电视，捏碎了手里的杯子，轻声说："我还没死，你急什么。"
- 为什么点下一章：他需要钱救妹妹，而他全身上下最值钱的东西，是他脑子里的整个体系。读者要看他怎么把"知识"变成第一块钱。
- 钩子类型：新目标 + 新身份悬念。

## 第2章 死人挣的第一块钱

- 核心吸引点：知识变现的第一次展示。
- 场景：筒子楼 → 黑潮地下拳场。
- 剧情：妹妹的稳蚀剂只剩两天。他去了地下拳场。不是打拳，是看拳：一个卡在三脉瓶颈两年的拳手今晚要打生死局，全场看衰。林夜用一根粉笔在墙上改了他运气路线的一个节点，开价五千。拳手死马当活马医。
- 释放：拳手当场破关，反杀对手。全场哗然，九指陈第一次注意到这个"瘦得跟竹竿一样的少年"。
- 代价：五千块只够四天的稳蚀剂。钱的速度追不上病的速度。
- 为什么点下一章：九指陈拦住了他："小兄弟，聊聊？"读者要看他怎么和灰色地带打交道，以及妹妹的病怎么办。
- 钩子类型：新人物 + 新危险（妹妹病情）。

## 第3章 稳蚀剂的真相

- 核心吸引点：世界真相的第一道裂缝（L1层级）。
- 场景：黑潮拳场后台 → 药店 → 家。
- 剧情：九指陈的"聊聊"：陈需要他这种"懂行的"，提出合作。林夜要钱，但提出先看货。在拳场的药材库里，他看了一眼稳蚀剂的成品，闻了闻，说出一句让陈变脸的话："这药里三成是安定剂。喝的人舒服，病的人烂根。"他第一次意识到：十年过去，他们连他的药剂都改了。改得更赚钱，也更毒。
- 释放：认知反转——他原以为敌人只是偷了他的成果，现在发现他们把成果变成了持续抽血的机器。妹妹的药，就是这机器的一环。仇恨从"私仇"升级为"系统性的账"。
- 为什么点下一章：他决定参加五天后的觉醒遴选——不是为了觉醒，是为了遴选背后的东西。读者要看一个体系作者怎么玩遴选。
- 钩子类型：新目标 + 信息差扩大。

## 第4章 遴选

- 核心吸引点：扮猪吃虎的第一个明爽点。
- 场景：临江市觉醒中心。
- 剧情：遴选现场，世家子弟排队用进口药剂，平民子弟挤普通窗口。周子昂在场，认出了"死掉的林夜"，当众发难。白青梧作为学院观察员在场。觉醒台上，所有人等着看这个没用药剂的旁听生出丑。
- 释放：他不用任何药剂，单凭呼吸站上觉醒台，三息开脉。检测水晶的反应是"觉醒异常完美"，仪器读数好到让工作人员以为仪器坏了。周子昂的脸，白青梧的眼。
- 控制：他随即"虚弱脱力"，把读数解释为"运气好"。扮猪吃虎守则：露一线，藏九分。
- 为什么点下一章：周子昂当众丢了脸，周家的报复一定会来；白青梧在登记表上把他的名字圈了起来。
- 钩子类型：新危险 + 新人物的怀疑。

## 第5章 周家的价码

- 核心吸引点：压力升级 + 主角第一次"谈生意"。
- 场景：第三武道学院 → 周家茶楼 → 家。
- 剧情：周炳坤没有喊打喊杀，而是出价：一笔钱，让林夜"忘了巷子里的事"，再签一份永不参加学院联赛的保证书（怕儿子当年打人的事在联赛舆论里翻出来）。糖衣后面是威胁：不签，你妹妹的药，临江一盒都买不到。
- 释放：林夜当面签了字，拿了钱。周子昂嘲笑他骨头贱。读者憋屈——然后反转：他出门就把签字的录音卖给了九指陈（录音里周炳坤亲口承认"药在我手里"），钱照收，局照做。他没打算忍，他只是需要周家亲口把刀递过来。
- 为什么点下一章：妹妹的药快断了，而他的"假药"计划需要第一笔原料钱和一个摊子。读者要看他怎么把药做出来。
- 钩子类型：意外结果 + 新计划。

## 第6章 假药

- 核心吸引点：财富 + 智胜双爽点。
- 场景：九指陈的仓库 → 家 → 黑市。
- 剧情：他用前世原始配方改出"清蚀散"（稳蚀剂的替代品，成本不到一成）。先给妹妹用：一夜退烧，第二天能下床。九指陈试卖一百份，黑市当天抢空。周家渠道里第一次出现"客户流失"。
- 释放：妹妹病情缓解（情感释放）+ 第一桶金到手（财富释放）。
- 代价与危机：陈提醒他：动稳蚀剂，动的不是周家，是云氏的药锅。果然，周炳坤拿到"假药"样品，脸色铁青："查。查出来源，做掉。"
- 为什么点下一章：周家的刀正式出鞘，而主角要赶在刀落下之前，先借到一把更大的刀。
- 钩子类型：新危险。

## 第7章 借刀

- 核心吸引点：规则利用爽点。
- 场景：守备军稽查队 → 周家仓库 → 报社。
- 剧情：他不等周家查到自己，主动出击：把周子昂倒卖学院药剂配额的证据（原主用命换来的那本账，藏在他家地板下——原主记忆里的死因拼图补齐）拆成三份，分别送给守备军稽查队、周家的对头、本地小报。稽查队当天查封周家一处仓库。
- 释放：周炳坤被叫去问话，临江药剂市场地震。主角全程没有露面。
- 代价：稽查队的动作也扫到了九指陈的场子，陈的利益受损，两人之间出现第一道裂缝（盟友不是仆从）。
- 为什么点下一章：周炳坤狗急跳墙，查到了"假药"最后一次交易的地点，派出了花钱雇的觉醒者杀手——目标：林夜和林溪。
- 钩子类型：新危险（直接生命威胁）。

## 第8章 过载

- 核心吸引点：绝境翻盘 + 主角付出代价。
- 场景：筒子楼 → 深夜窄巷。
- 剧情：杀手二境巅峰，主角身体只有一境初。硬拼必死。他把妹妹锁进屋里，一个人把杀手引进窄巷。用完整版功法里才有记载的"过载路径"，三招之内越级搏杀。
- 释放：反杀。全书第一场硬战，用体系知识打出不可能的结果。
- 代价（必须真实）：过载的代价是经脉撕裂般的损伤，他在巷子里吐了半晌血，扶着墙挪回家，进门之前把血擦干净。第二天妹妹问他脸色怎么这么差，他说没睡好。
- 为什么点下一章：杀手有雇主记录，周炳坤买凶杀人的链条留下了活口。周家的死期到了——但更大的眼睛也在看向临江。
- 钩子类型：新证据 + 新危机（远景）。

## 第9章 周家倒

- 核心吸引点：复仇兑现（第一层小账）。
- 场景：守备军 → 周家老宅 → 医院。
- 剧情：买凶证据 + 走私证据 + 倒卖配额，三案并爆。守备军正式立案，云氏药业第一时间切割，宣布"终止与周家的代理合作"（杜衡首次以名字出场，人未至，刀先到）。周炳坤在自家客厅被带走。周子昂在学院被除名。
- 释放：当众清算。临江人议论了一个月的第一大瓜。原主林夜的死亡真相第一次被公开记录（"意外斗殴"改口为"故意伤害致死"）。
- 情感点：林夜带着妹妹去给父母上坟，把报纸在坟前烧了。他没哭，站了很久。
- 为什么点下一章：学院联赛/市里大比的请柬送到，白青梧点名要他参加。而他想躲——他需要一个"合理消失"，但请柬背后的人不给他躲的余地。
- 钩子类型：新事件 + 关键选择。

## 第10章 大比

- 核心吸引点：阶段小高潮 + 身份线第一次炸雷。
- 场景：临江市体育场（青年武道大比）。
- 剧情：全市直播的青年大比。周家余党买通了对手，要在台上"正当"地废了他（最后一个报复）。白青梧在场边，九指陈在台下，秦教授在观众席。对手是二境武者，台上招招下死手。林夜不再藏拙：用一套在场没人见过的起手式，十招之内把对手钉在台上。
- 释放：公开胜利 + 周家残余被当众钉死 + "临江出了个怪物"的话题度。
- 大钩子（章末最后三百字）：比赛画面进了当晚的省级新闻集锦。千里之外，京畿。某间办公室里，一个正在批文件的女人（云萝）抬头看了一眼屏幕，手里的笔停住了。那个起手式，全世界只有一个人会那样起。她盯着屏幕上那张年轻的、陌生的脸，看了很久很久，然后按下内线："查一个人。临江，林夜。"
- 为什么点下一章：身份悬疑从"暗线"变成"明雷"。读者必须看下一章：她会查到什么？他怎么应对？
- 钩子类型：新身份危机（最高级别）。

## 前十章爽点类型核对（防重复）

1章：悬念爽（死而复生）+ 仇恨锚点
2章：技能碾压（知识变现）
3章：信息差（认知反转）
4章：扮猪吃虎（众人误判）
5章：智胜（将计就计）
6章：财富 + 愿望实现（救妹妹）
7章：规则利用（借刀）
8章：绝境翻盘（越级反杀，付代价）
9章：复仇兑现（周家倒台）
10章：竞争胜利 + 身份悬疑炸雷

十种爽点无一重复，压力与释放交替，强度曲线逐步抬升，符合宪法第4、19条。
