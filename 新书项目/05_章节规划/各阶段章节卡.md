## 第一章章节卡（已执行）

```text
章节：第一章 · 我还没死
时间：界渊50年深秋，顾北辰忌日当夜（第1天）
地点：仁爱诊所停尸间 → 雨夜街道 → 筒子楼家中

本章主角欲望：活下去（先不被"处理"掉，再活过这两天）

本章主要人物：林夜/顾北辰、诊所医生（声音）、收尸人甲乙、林溪、贺擎苍（电视里）

人物各自目标：医生要钱；收尸人要交差；林夜要脱身回家；贺擎苍要表演哀痛

主要冲突：已死之人必须在被拉走前逃出去

阻碍：濒死的身体、两个收尸人、身无分文、雨夜三站地

信息差：读者与主角知他复活且是顾北辰；全世界不知；周家以为尸体将被处理

本章爽点：死而复生悬念爽 + 三指放倒收尸人（体系作者第一次小露）+ 对电视仇人那句话（仇恨锚点）

本章反转：尸体开口说"别动"（R01）

人物关系变化：无（全是新关系建立）

主角付出：强行引源，经脉受损（鼻血、黑点）、手掌割伤

主角获得：八百六十五块、棉服一件、回家的身份入口

本章新信息：现在是十年后；他死于北海之眼；官方定性"走火入魔"；稳蚀剂三百八一盒；林溪药只剩四顿

本章未解决问题：钱不够；周家马上会知道他还活着；药的死线两天后到期

结尾钩子：八百六十五块数了两遍，两盒药七百六，房租水电还没算

短剧高能场景：白布单下睁眼、剪子抵喉、捏碎杯子对电视说话

动态漫高能场景：源力第一次入体、烧起来的雪与站成一圈的人（记忆碎片）
```

## 第三章章节卡（已执行）

```text
章节：第三章 · 稳蚀剂的真相
时间：界渊50年第3天（凌晨至当晚）
地点：黑潮二楼办公室 → 后侧药材库 → 街口药店 → 筒子楼家中

本章主角欲望：把"懂行"变成稳定来钱路；给妹妹续上药

本章主要人物：林夜、九指陈、黑棉袄（打断）、药店店员、林溪

人物各自目标：陈=摸底细收为己用；林夜=钱+药的信息；店员=卖货；林溪=确认哥没骗人

主要冲突：谈判互探（陈要人，夜要钱）；真相揭开的情绪冲击

阻碍：陈的老练盘问；林夜不能说真话；药钱死线

信息差：陈只知他"懂行"不知底细；林夜本章才知药剂被改；读者与林夜同步

本章爽点：S03 认知反转（稳蚀剂=抽血机）+ 谈判不落下风

本章反转：R02 稳蚀剂不是治病药，是抽血机

人物关系变化：林夜×九指陈 目击对象→看货合作（互相利用起步）

主角付出：暴露风险计息（陈好奇"什么来路"）；情绪重击（妹妹喝烂根药且还得继续喝）

主角获得：黑潮看货合作（一次两百）、稳蚀剂真相、遴选情报、五盒药

本章新信息：三成安定剂烂根；云氏产药周家代销全城一个价；五天后遴选、觉醒药剂两千八

本章未解决问题：药怎么办（Q10）；遴选怎么过（Q11）；陈会不会拿真相做文章（Q12）

结尾钩子：他决定去遴选（棋子转了三圈，停了）

短剧高能场景：药材库验药"兑了三成"；缺指陈盘核桃变脸；妹妹凑近验眼睛

动态漫高能场景：灯管闪的药材库、核桃停转
```
