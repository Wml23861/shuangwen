# 源武体系（能力体系）

## 公开体系（世人所练）

### 觉醒（开脉）

- 年满十六岁，在觉醒中心服用觉醒药剂，由引导师协助冲击第一条主脉。
- 官方成功率约三成。失败者可次年重试，药剂费用自理。
- 觉醒后源力入体，成为一境武者。

### 境界划分

| 境界 | 称呼 | 说明 |
|---|---|---|
| 一境 | 武者 | 开一脉，体能全面超越常人 |
| 二境 | 武者 | 开三脉，可外放微弱源力 |
| 三境 | 武者 | 开六脉，源力护体 |
| 四境 | 武师 | 主脉成环，可驱动源武技 |
| 五境 | 武师 | 源力凝实，独当一面（杜衡在此境） |
| 六境 | 武师 | 源力外放成形 |
| 七境 | 宗师 | 一方宗师，可开宗立派 |
| 八境 | 圣者 | 当世仅七柱 |
| 九境 | 传说 | 无人达到。顾北辰死于此门槛（官方说法） |

### 功法

- 《基础源武十二式》：全民必修，总会颁布。实际为顾北辰完整体系的阉割版。
- 高阶功法：分级管制，价格高昂，世家垄断。

### 药剂

- 觉醒药剂：觉醒辅助，一次性，贵。
- 稳蚀剂：源蚀症缓解药，终身服用，持续抽血。
- 军用源剂：管制，战场恢复与爆发用。

## 底层真相（仅主角知道的"后门"清单）

> 这是主角金手指的技术底账。每一个"后门"对应未来至少一个爽点。使用时必须控制节奏，一章最多抖一个。

1. 引源呼吸术：觉醒根本不需要药剂。呼吸节律 + 特定引导手法即可开脉。他创的原始版本，被雪藏。
2. 完整功法：十二式的完整版是三十六式，且阉割版的发力顺序被故意改错两处，导致修炼变慢、暗伤累积、源蚀症高发。
3. 经脉过载技：短时间让经脉超载运行的爆发技巧，威力翻倍，代价是经脉损伤。原版功法里有安全的过载路径，阉割版没有。
4. 药剂缺陷：觉醒药剂里的"凝源剂"成分会残留经脉，是源蚀症的帮凶之一。他知道替代方案。
5. 源蚀症根治方向：他死前已推演出思路（净化经脉 + 重修引源），缺一味当时没有的媒介（伏笔：界渊深处的某种东西）。
6. 九境之秘：他死前摸到的门径内容（长期保留，作为后期升级线）。

## 主角实力恢复线

| 阶段 | 身体状态 | 对外展现 |
|---|---|---|
| 第1至5章 | 濒死废柴，未觉醒 | 无药剂暗中引源，修复暗伤 |
| 第6至15章 | 一境（隐藏） | 伪装"刚觉醒"，实战靠技巧碾压同境 |
| 第16至30章 | 一境巅峰至二境 | 越级挑战的资本来自技巧与体系理解 |
| 第二阶段 | 二境至三境 | 逐步"合理化"自己的天才速度 |

## 使用原则

- 主角强在"知道"，不强在"数值"。每一次碾压都必须让读者看清他用了哪个后门，爽得有理。
- 后门不能连用，同一后门短期不重复使用（爽点升级系统，宪法第4条）。
- 身体限制必须真实：使用超出身体承受的技巧必须有代价（第8章的过载即为例证）。
