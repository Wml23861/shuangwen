# 书名候选

> 宪法第70条：最终书名必须由用户决定。以下仅作候选与分析，不宣布任何一个"一定最好"。

## 候选名单

### A组：身份反差流（主打点击）

1. 《我死后十年，仇人成了世界英雄》
   - 核心卖点：身份反转 + 复仇，冲突直接写在书名里
   - 优点：信息量大，悬念和仇恨一句到位，番茄点击型书名的标准结构
   - 风险：略长

2. 《死后十年，我回来收账了》
   - 核心卖点：归来 + 复仇，口语化，有短剧感
   - 优点：好记，短视频传播友好
   - 风险：高武感弱

3. 《我死后，全世界都在用我的功法》
   - 核心卖点：体系作者设定，直接亮金手指
   - 优点：一句话说清本书独特性，好奇感强
   - 风险：复仇线不明显

### B组：高武品类流（主打分类流量）

4. 《高武：我死后十年归来》
   - 优点：分类词前置，吃"高武"搜索流量，番茄常见结构
   - 风险：同质化前缀多

5. 《高武：全世界都在练我创的功法》
   - 优点：分类流量 + 独特设定兼得
   - 风险：书名长

### C组：情绪流（主打昭雪感）

6. 《他们杀了我，又拜了我十年》
   - 优点：委屈感 + 悬念极强，记忆点高
   - 风险：品类信息缺失

7. 《武道之祖已死十年》
   - 优点：悬念型，"已死"暗示归来，气质偏正
   - 风险：爽感不直接

## 初步分析

- 番茄男频当前点击验证最稳的结构是 A 组：冲突或身份反差直接写进书名。
- B 组适合吃分类自然流量，可与 A 组思路合并，例如《高武：我死后十年，仇人成了世界英雄》（偏长）。
- C 组适合短视频切片传播，可作副标题或宣传语。

## 推荐方向（供用户拍板）

首选方向：A1《我死后十年，仇人成了世界英雄》
理由：一句话同时交付身份反转、复仇、世界观三个钩子，与简介第一句可直接咬合。

最终决定权：用户。
